## B · Concept test (run on every finalist)
- [ ] Reads as 11 (not 110 or 101) to someone who hasn't seen it before
- [ ] Emblem unchanged
- [ ] 16 px and 32 px legible
- [ ] One-colour version works
- [ ] 9 backgrounds pass (Figma 04 grid)
- [ ] Prints flat, with gradients optional
- [ ] Sits well beside the master logo
- [ ] Not too similar to existing marks (reverse image search)

## C · Final deliverables
- [ ] Primary mark: full colour
- [ ] Horizontal lockup and stacked lockup
- [ ] Icon / favicon set (16, 32, 48, 180, 512 px plus ICO)
- [ ] Social avatar crop
- [ ] One-colour: deep green, black, white
- [ ] Reversed (on navy `#020D19` and on deep green)
- [ ] **Urdu version (required):** ۱۱ سال, حماد فاؤنڈیشن, plus Urdu lockup with the master logo
- [ ] Lockup with the master logo
- [ ] Colour specs: HEX, RGB, CMYK, Pantone (greens, gold, flat gold)
- [ ] Clear-space and minimum-size rules (print mm, screen px)
- [ ] Misuse examples (stretch, recolour, effects, crowding, emblem edits)
- [ ] Usage window: 2027 only
- [ ] Files: AI, PDF, EPS, SVG (outlined); PNG transparent @1x/@2x/@4x; JPG previews
- [ ] Presentation PDF (16:9, under 15 MB)
- [ ] Guidelines pages (inside the PDF or standalone)
